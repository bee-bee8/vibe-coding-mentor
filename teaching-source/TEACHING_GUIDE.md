# Codex Mentor Teaching Source

This is the original, public teaching reference used by Teaching Mode. It
helps explanations connect programming ideas to the frozen code in one current
change.

## Teaching rules

- Start with the user's selected level and explain only that level.
- Use the Change Record and frozen changed-file evidence as the source of truth.
- Introduce concepts in prerequisite order and connect each one to a real file.
- Prefer a small analogy followed by precise code-based language.
- Name uncertainty instead of inventing context from the wider repository.
- Beginner explanations emphasize sequence, purpose, and vocabulary.
- Intermediate explanations emphasize boundaries, data flow, trade-offs, and tests.

The source is deliberately concise. The model adapts it to the supplied change
without loading the other learning level or scanning the project.
